# Hey, I'm Poramet.
That's it, I guess. I made tools to fix my silly problems. It might also be useful for other so below is the list of tools I made. Not all of them, obviously. You can find the rest in my repos.

# Tools!

## [Keyswap](https://c-poramet.github.io/Keyswap/)
Convert texts that are mistakenly typed in wrong layout of keyboards between TH/EN.

## [Wordle Solver](https://c-poramet.github.io/WordleSolver/)
Solve Wordle based on multiple guesses you have made.

## [Prefix Finder](https://c-poramet.github.io/lastLetter/)
Look up words that starting with the input string.

## [DTicket Helper](https://dticket-helper.onrender.com/)
A tool to help with finding the cheapest Thai train ticket. **WIP**

## [GPS : Grid Puzzle Solver](https://c-poramet.github.io/GridPuzzleSolver/)
A tool with a custom language called GSL (Grid Solver Lanaguage) to help with solving those online grid puzzles. You will **DEFINITELY** need the [README](https://github.com/c-poramet/GridPuzzleSolver).

## [Split Zip File](https://github.com/c-poramet/Split-Zip-File/)
A python script for zipping a file into smaller zip files. Made it for myself to send big files over Discord.

## [Hear The Color](https://c-poramet.github.io/hear_the_colors/)
A site to turn an audio file into a color using a certain set of configuration, mostly by birthdays. I have no idea what is the purpose of this thing.
